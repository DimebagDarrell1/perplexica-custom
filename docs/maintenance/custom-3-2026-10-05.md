# Custom 3: search sources, page reading and ChatGPT plan sign-in

Build `1.12.1-dorian.3`. Rebuild and recreate the Unraid service to install it.

## Search discovery

The bundled SearXNG moved from a March 9 commit to `d48c4b5` (October 4),
541 commits newer. The new build replaces its HTTP client with `curl_cffi`.

The app's default engine list was partly dead on the new build. Startpage and
Mojeek are inactive there, and `aol` was never a valid engine name. The list
is now `google cse`, `bing`, `brave`, `yandex`, `yahoo` and `wikipedia`. In a
local test against the new SearXNG, four sample queries returned 43 to 49
results from four engines each, against 21 results from two engines with the
old list. Brave was rate-limited from that network.

SearXNG also dropped its Reddit engine, so Discussion search returned general
web results. It now searches `site:reddit.com` through the general engines and
keeps only Reddit pages.

## Page reading

Firecrawl can be turned on in **Settings → Search** with its URL and optional
key. Saved settings take precedence over the `FIRECRAWL_*` variables. Balanced
and Quality modes try Firecrawl first and fall back to the built-in reader.
A live read of LAIKA's Coraline page through the self-hosted Firecrawl took
13.4 seconds and returned 32,648 characters, so the Firecrawl timeout default
is now 15 seconds.

Pages are now read by a worker pool instead of fixed batches of five. A slow
page no longer delays the pages queued behind it. Each read has its own
deadline (9 s in Speed, 20 s in Balanced and Quality) covering Firecrawl and
every fallback, and Balanced and Quality read 6 and 8 pages at once.

## ChatGPT plan

**Settings → Models** has a **Use your ChatGPT plan** panel. Signing in
registers Perplexica with OpenAI and adds a **ChatGPT plan** connection whose
models come from your account. See [the setup guide](../installation/CHATGPT_PLAN.md).

## Upstream fixes

- PDF and Markdown exports use the saved answer text without `<think>`
  reasoning, so PDFs no longer print raw `<citation>` tags (upstream #1126).
- YouTube no-cookie embeds play in the video lightbox (upstream #1049).
- Chat and reconnect streams send a `keepAlive` line after 15 quiet seconds
  and set `X-Accel-Buffering: no`, so nginx-based proxies neither close nor
  buffer long answers (upstream #1051, adapted).
